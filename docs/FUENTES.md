# Fuentes autoalojadas

Las mismas familias tipográficas de la Evaluación N°2, descargadas como WOFF2 (subconjunto latino)
para no depender de Google Fonts en tiempo de ejecución y poder precargarlas desde `index.html`.

| Archivo | Familia | Uso |
| --- | --- | --- |
| `medievalsharp-latin-400-normal.woff2` | MedievalSharp | Títulos |
| `cinzel-latin-400-normal.woff2` | Cinzel | Navegación, etiquetas y botones |
| `crimson-text-latin-400-normal.woff2` / `-italic.woff2` | Crimson Text | Texto corrido |
